# 비대면 서비스 법령 판단보드

베트남 거주 한국 교민을 대상으로 한 비대면 상담·진료 서비스의 한국 법령 판단보드입니다.
2026년 9월 기준 법령을 다루며, **법률 자문이 아닙니다.**

## 웹에서 보기

https://butblank-oss.github.io/telehealth/

## 구성

`index.html` 한 파일로 동작하는 정적 페이지입니다. 빌드 과정이나 서버가 필요 없고,
파일을 브라우저에서 직접 열어도 동일하게 동작합니다.

- 01 결론
- 02 질문 판정표 — 11개 질문. 상담/진료 판정과 근거 조문, 처벌 수준, 검증 신뢰도, 확인 필요 창구를 항목별로 펼쳐 볼 수 있습니다.
- 03 상담과 진료의 경계선 가이드
- 04 상담 개시 전 체크리스트
- 05 시장 조사
- 백업 — 약어·용어 풀이, 규제 분류, 인용 법령 목록

판정표의 필터와 펼치기는 페이지 안의 바닐라 JavaScript로 동작합니다.
외부 의존성은 웹폰트(Pretendard, Newsreader, Paperlogy) CDN뿐입니다.

## 협진톡 (HyeopjinTalk)

의사 간 협진 메신저입니다. 법령 판단보드와 별개의 페이지로, `hyeopjintok/` 아래에 있습니다.

https://butblank-oss.github.io/telehealth/hyeopjintok/

베트남 현지 의사와 한국 의사가 **환자별로 대화하고 자료를 남기는 폐쇄형 메신저**입니다.
카카오톡 협진의 두 가지 문제 — 여러 환자 이야기가 한 창에 섞이는 것, 사진·파일이 만료되어
사라지는 것 — 을 **환자 1명 = 방 1개**, **자료 만료 없음**이라는 구조로 해결합니다.

**환자는 이 서비스를 사용하지 않습니다.** 환자용 화면도 계정도 없습니다. 환자는 현지 병원에서
대면 진료를 받고, 자료 등록과 대화는 의사끼리만 합니다. 의료법 제34조의 의료인 간 원격협력
구조를 전제로 하며, 환자에 대한 책임은 같은 조 제4항에 따라 현지 의사에게 있습니다. 따라서
UI 카피에서 "진료"·"처방" 대신 "협진"·"의견"을 씁니다.

### 화면

로그인 / 초대 수락 온보딩(4단계) / 환자 목록 / 협진 방 / 환자 정보·자료 패널 /
전역 검색 / 알림 / 내 정보 / 운영자(사용 현황·감사 로그·의사 관리).
PC는 3열(레일 292px · 본문 · 패널 264px), 1010px 미만에서는 하단 탭바 단일 컬럼으로 바뀝니다.

### 지켜야 하는 규칙

화면을 고칠 때 이 셋은 깨뜨리지 않습니다.

- **환자 이름은 가린다.** 진료실 모니터는 환자가 봅니다. 화면에 뜨는 환자 이름은 `pname()`을
  거쳐 띄어쓰기로 나눈 각 낱말의 가운데를 가립니다(김성호 → 김*호). 방 안에서 눈 버튼으로
  잠깐 풀 수 있고, 내 정보에서 아예 끌 수 있습니다. 이름을 새로 그리는 자리가 생기면
  반드시 `pname()`을 씁니다.
- **자동 추정값은 소견이 아니다.** 사진에서 어림한 값은 `자동 추정` 배지와 `≈`를 달고
  점선 안에 들어갑니다. 의사가 쓴 문장과 같은 무게로 보이면 안 됩니다.
- **문의는 둘 이상일 때만 보인다.** 방에는 문의(thread)가 늘 하나 이상 있지만, 화면에
  주제 바와 구분선이 나오는 것은 둘 이상일 때뿐입니다. 방 목록이 `문의 1`을 숨기고
  `문의 2`부터 보여주는 규칙과 같습니다. 방 안 검색은 문의 개수와 무관하게 동작합니다.

새 협진을 만들 때 적은 문의 문장은 제목이 아니라 **내가 보낸 첫 메시지**가 됩니다.

### 구성

`hyeopjintok/index.html` 한 파일로 동작합니다. 빌드도 서버도 없고, 디자인 토큰·컴포넌트 CSS·
상태 관리·렌더링이 모두 이 파일 안에 있습니다. 외부 의존성은 웹폰트(Pretendard) CDN뿐이며,
아이콘은 인라인 SVG입니다.

데이터는 데모용 시드입니다. 새로고침하면 처음 상태로 돌아갑니다.
화면 이동은 해시 라우팅(`#/room/p1`, `#/admin` 등)으로 주소에 남습니다.
